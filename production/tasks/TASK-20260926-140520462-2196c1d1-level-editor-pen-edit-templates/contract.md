## Objective and baseline

- Observable objective: With the Pen, a left click on a block starts editing it: the block is highlighted, the free neighbour cells it can grow into show green, and its piece's Blocks tile is outlined. Edits work for templates (library pieces) and custom pieces; a template edit changes every block of that template in the open level at once, a banner at the top warns that it reaches all blocks, and Save Level writes the new footprint to the piece library and re-stamps the template's blocks in the other levels of the active database.
- Current behavior/evidence (2026-09-26, `Editor/Levels/LevelDatabaseWindow.cs`, `Canvas/LevelCanvasElement.cs`, `Canvas/LevelShapePalette.cs`, `Editor/BoardKit/ShapeLibraryAuthoring.cs`; design maps and critic in this session's workflow wf_933fcf76-d5e):
  - The plain Pen edits whatever block is selected, including the automatic default selection; a Pen press on another block does nothing; no neighbour cells are shown before hovering; the palette does not mark the edited piece.
  - A swatch recolours only a block chosen with Select (`m_blockChosen`).
  - A Pen edit of a library block turns it into a new named level piece for that block only (`TryGetEditPiece`); the template never changes.
  - `ShapeLibraryAuthoring` has an internal `Commit(library, shapes, label, recordUndo, expectedDisk)` that replaces records, regenerates stale prefabs and writes the piece JSON; a cells-only change writes no enum. `SaveLevels` writes every level of the active database JSON in one atomic replace.
  - User request (2026-09-26, verbatim): "burada çizim modunda seçili parça gözükebilir ve çizebileceğimiz komşularda gözükebilir, örnek olarak parçayı yerleştirince eğer elime kalem alıp o parçaya sol tıklarsam parçanın çizebileceğim komşuları gözüksün editleme böyle başlar ve blocsdan da parça seçili gözükür, rengini değiştirebilirim paröanın ve template veya custom olsa da editleyebilirim ve uyarı olarak template de yapılan değişiklikler bütün parçalara yansır diye edit esnasında uyarı geçebiliriz üst tarfta." Answers to the follow-up questions (the user selected these options; option text verbatim): template scope "Template, saved on Save Level (Recommended)" — "Every block of that template in this level changes at once (one undo step per stroke). Save Level then writes the new footprint to the piece library through the Piece Editor's library commit, so other levels and the game use it too. A level that cannot take the new footprint (off-board, overlap, void or board object) is never forced: Save Level lists those levels in one confirm (Cancel by default); "Save and leave those levels unchanged" writes everything else and leaves all listed levels on the old footprint (one choice for the whole list, not per level); the status names them and the custom-pieces AC-9 banner then shows them as changed library blocks for a manual Re-stamp.

  - Empty-space click (user revision of 2026-09-26: "boş bir yere sol veya sağ tıkalrsak da edit mode dan çıkabiliriz ve selection da kapanabilir"): with the plain Pen, a left or right click on an empty spot (a free board cell that is not a green cell, or outside the board) ends the edit and clears the selection; with Select, a left click on an empty spot (when no piece is picked) or a right click on an empty spot clears the selection.

## Observation

The locked nodes 2 and 3 no longer show the blue rounded square: only four small blue corner pieces are drawn
around the numeral, with the rail visible through the middle. The current node 1 and the Level button are correct.

CONFIRMED_ROOT_CAUSE: the cycle-6 D-009 fix declares `-unity-slice-left/top/right/bottom: 97/164/97/162` and
`-unity-slice-scale: 0.5px` on `.route-node`. `.route-node--locked` inherits them but draws
`Btn_settings_normal.png` (134 x 139, importer border 0,0,0,0), so borders larger than the texture leave only the
corner regions.

## Reproduction

1. Play Hub (or run `HubCaptureTests.CaptureHome` with `CBJ_HUB_CAPTURE=1`).
2. Look at the locked nodes 2 and 3 above the current node.
3. Observe four blue corner fragments instead of a blue rounded square.

## Expected and actual

- Expected: the locked nodes show the whole `Btn_settings_normal.png` rounded square with its lock, as before
  cycle 6, while the current node keeps the D-009 square; no "Sprite borders are overridden" warning.
- Actual: the locked nodes inherit the current node's slice values and show only corner fragments.

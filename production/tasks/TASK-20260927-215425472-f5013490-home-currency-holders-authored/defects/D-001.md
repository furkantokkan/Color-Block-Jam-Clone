## Observation

Opening Home by itself in UI Builder shows unstyled currency text and default grey button backgrounds. Route numeral layers separate vertically and the Level button has no preview text. The user reports that the game looks correct.

## Reproduction

1. Open `Assets/ColorBlockJam/UI/Hub/Home.uxml` in UI Builder without Play Mode.
2. Use a 1080 x 1920 canvas with the default runtime theme.
3. Compare the authored top bar and route with the running Home screen.

## Expected and actual

- Expected: The authored life and coin holders show their finished runtime appearance without Play Mode; the rest of Home remains editable and recognisable.
- Actual: Shared button resets, title styles, heavy-text positioning and the runtime font are supplied only by the panel theme, so a standalone Home document loses them.

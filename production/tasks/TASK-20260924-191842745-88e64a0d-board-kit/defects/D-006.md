## Reproduction

1. After the 2026-09-25 cleanup, the highest enum ID is 29, so the Piece Editor gives the next new piece ID 30
   (`NewPieceTest = 30`) with a new `Piece_030.prefab` GUID.
2. Run `ShapeLibraryJsonTests.ProductionLibraryMatchesCanonicalJsonAndRetainsPrefabIdentities`.
3. The historical-binding loop sees ID 30 defined again and loads the pre-cleanup GUID
   `24c318532ec336544b6bfd11e416e6eb` (historical type `CTypeL`, moved to the piece backups). The GUID resolves
   to no prefab and the assertion fails. Delete keeps ID 30 reserved, so deleting the piece does not clear it.

- Expected: surviving original identities keep their original prefab GUIDs, and an ID freed by the cleanup can be
  reused by a new piece with its own prefab (the cleanup note: new pieces receive ID 30 and above).
- Actual: the test treats every defined ID as an original identity and fails for the first new piece.

## Observation

The canvas effect layer shows bare numeric text over diagonal frost strokes. It has no distinct snowflake/count badge promised by the accepted presentation design.

## Reproduction

1. Set a canvas model containing Ice with count 1 or 20.
2. Inspect `IceCanvasEffectLayer.SetModel`, `Position` and `Draw`.
3. The only label is a bare number and the only frost symbol is one diagonal stroke per cell; no separate badge or snowflake is drawn.

## Expected and actual

- Expected: A distinct pale-blue frost/count badge that remains separate from block IDs, selection and existing Arrow markers.

## Observation

With the rotate-clockwise tool, each click on a block should turn it another 90 degrees to the right, but the block only goes back and forth between 0 and 90 degrees.

## Reproduction

1. Open the Level Editor window with a level holding a 1x2 block (for example B3, DoubleHorizontal).
2. Pick up the rotate-clockwise tool and left-click the block several times.
3. The block alternates between horizontal and vertical at the same bottom-left cell; clicks 3 and 4 look like clicks 1 and 2.

## Expected and actual

- Expected: each click is a visible 90-degree clockwise step, and four clicks bring the block back to its start (contract AC-3 as revised on 2026-09-26).
- Actual: the rotated footprint is shifted back to start at the block's unchanged origin, so for a symmetric piece a 180-degree turn looks the same as no turn.

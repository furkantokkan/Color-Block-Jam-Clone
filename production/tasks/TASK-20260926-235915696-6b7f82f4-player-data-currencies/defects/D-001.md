## Observation

`Assets/ColorBlockJam/Editor/Data/ColorBlockJamDataSetup.cs:122` (`CreateBoosterDefinition`)
sets `serialized.FindProperty("m_purchaseCoinPrice").intValue = 10`. That serialized field no
longer exists, and the tool never sets the new purchase currency.

## Reproduction

1. Delete or rename any booster asset under `Assets/ColorBlockJam/Data/Boosters/Definitions/`.
2. Run the menu `Color Block Jam > Data > Create Default Assets`.
3. `FindProperty` returns null and a `NullReferenceException` stops asset creation.

## Expected and actual

- Expected: the data-setup tool recreates a missing booster definition that passes
  `BoosterDefinition.Validate` (price 10 in Coins).
- Actual: it throws; even without the exception the recreated asset would lack
  `m_purchaseCurrency` and fail validation.

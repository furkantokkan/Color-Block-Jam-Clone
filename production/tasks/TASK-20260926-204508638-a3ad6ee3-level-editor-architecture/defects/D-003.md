## Observation

The piece controller's pure catalog refresh can consume a library JSON identity change before the window updates palette controls or disarms an obsolete shape. If drawing/removing a cell or separating a piece then refuses the edit, subsequent window refresh sees the consumed identity and leaves the view stale.

## Reproduction

1. Change the transient piece library while a window still has the preceding catalog.
2. Attempt a custom-piece operation that refreshes the catalog but refuses or makes no edit.
3. Observe that the extracted refresh lacks the original window's palette/banner/disarm effects.

## Expected and actual

- Expected: Catalog identity and its dependent view state refresh together before planning an edit.
- Actual: The controller refreshes catalog identity alone; a rejected operation skips the later draft refresh.

## Observation

Level JSON v2 added void cells, block and door effects and cell objects to `LevelData`. Every Level Editor command (move, recolour, rotate, gate paint/extend/remove/recolour, resize) rebuilds records through `LevelRecordCopy`, which still calls the v1 constructors. Any edit on a level with v2 content silently drops it, and the next Save writes the loss.

## Reproduction

1. Build a `LevelData` with a void cell, a block effect (for example ice), a door effect (iced-door) and a cell object (barrier).
2. Run any `LevelEditCommands` command on it, for example `TryRecolorBlock` or `TryResizeBoard` Top +1.
3. The result has zero void cells, zero effects and zero cell objects.

## Expected and actual

- Expected: every field the command does not edit is copied; a resize shifts void cells and cell objects with the content and reports objects it removes.
- Actual: v2 fields are dropped by every command.
